# API guide

The source of truth is [`packages/api-contract/openapi.json`](../packages/api-contract/openapi.json), regenerated from the server's zod schemas (see [DEV.md](DEV.md)). This page is the short prose version.

## Conventions

- Base path `/api`. JSON in and out. Errors use `ErrorResponse` (`statusCode`, `error`, `message`).
- Authentication is a bearer token from `POST /api/auth/login` or `POST /api/auth/setup`, sent as `Authorization: Bearer <token>`. Every `/api` route requires it except the ones marked public below. Missing or unknown token returns 401.
- Admin-only routes return 403 for non-admin profiles.
- Ids are opaque strings. Timestamps are ISO 8601 UTC. Durations and positions are integer milliseconds.
- List endpoints take `offset` and `limit` (max 200) and return `{ items, total, offset, limit }`.

## Routes available now

| Route                            | Auth                  | Purpose                                                                                                                                                                                                                                                                                                                                              |
| -------------------------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /api/health`                | public                | Liveness. Returns `status`, server `version`, and current `time`.                                                                                                                                                                                                                                                                                    |
| `GET /api/auth/setup`            | public                | `{ needsSetup }`, true until the first admin exists.                                                                                                                                                                                                                                                                                                 |
| `POST /api/auth/setup`           | public                | Create the first admin profile from `{ name, pin }` and return `{ token, profile }`. 409 once any profile exists.                                                                                                                                                                                                                                    |
| `GET /api/auth/profiles`         | public                | Profiles for the login screen: id, name, admin flag, avatar colour.                                                                                                                                                                                                                                                                                  |

| `GET /api/auth/me`               | token                 | The profile behind the token.                                                                                                                                                                                                                                                                                                                        |
| `POST /api/auth/logout`          | token                 | Revoke the current token. 204.                                                                                                                                                                                                                                                                                                                       |
| `GET /api/auth/sessions`         | token                 | Devices logged in to this profile, with `current` marking the caller.                                                                                                                                                                                                                                                                                |
| `DELETE /api/auth/sessions/{id}` | token                 | Log out another device. 404 if not yours.                                                                                                                                                                                                                                                                                                            |
| `GET /api/libraries`             | token                 | All libraries with kind, paths, and last scan time.                                                                                                                                                                                                                                                                                                  |
| `GET /api/libraries/{id}`        | token                 | One library.                                                                                                                                                                                                                                                                                                                                         |
| `POST /api/libraries`            | admin                 | Create from `{ name, kind, paths }`. Every path must be an existing directory; duplicates are collapsed. 201.                                                                                                                                                                                                                                        |
| `DELETE /api/libraries/{id}`     | admin                 | Delete the library and, by cascade, every file, item, and stream indexed from it. 204.                                                                                                                                                                                                                                                               |
| `POST /api/libraries/{id}/scan`  | admin                 | Queue a scan and return 202 with the current `ScanStatus`. A library already queued is not queued twice; one already running is rerun once it finishes.                                                                                                                                                                                              |
| `GET /api/libraries/{id}/scan`   | token                 | Latest `ScanStatus`: `state` (`idle`/`running`), `phase` (`walking`, `probing`, `identifying`, `matching`), counters, `startedAt`, `finishedAt`, `error`. Poll until `state` is `idle` and `finishedAt` is set.                                                                                                                                      |
| `GET /api/items`                 | token                 | Browse. Query: `libraryKind`, `kind`, `parentId`, `search`, `needsReview`, `sort` (`title`, `year`, `added`, `lastPlayed`), `offset`, `limit`. Without `kind` or `parentId` it lists movies and shows; `parentId` of a show lists its seasons, of a season its episodes. Returns `{ items, total, offset, limit }` of `ItemSummary`.                 |
| `GET /api/items/{id}`            | token                 | `ItemDetail`: summary plus overview, genres, ids, `files` (each with `streams`), and `children` (seasons of a show, episodes of a season). 404 if unknown.                                                                                                                                                                                           |
| `GET /api/items/{id}/candidates` | admin                 | Possible matches for a movie or show. Query `query` (defaults to the item title) and `year`. Returns `MatchCandidate[]` from TMDB, plus AniList first for anime shows, best score first.                                                                                                                                                             |
| `POST /api/items/{id}/match`     | admin                 | Apply a match and refetch metadata. Movies and TV shows: `{ tmdbId }`. Anime shows: any of `anilistId`, `tmdbId`, `seasonOffset`; the offset is added to absolute episode numbers before mapping onto TMDB seasons and triggers a remap. Returns the updated `ItemDetail`. 400 when nothing applicable is given or TMDB is needed but no key is set. |
| `GET /api/images/{key}`          | public                | Cached artwork as JPEG. `?w=300                                                                                                                                                                                                                                                                                                                      | 780 | 1280`resizes on first request and caches the variant. Keys are SHA-1 hashes of the source URL and come from`posterKey`, `backdropKey`, or an episode still on items. Immutable cache headers. |
| `GET /api/settings`              | admin                 | Server settings with secrets masked to `{ set, hint }`.                                                                                                                                                                                                                                                                                              |
| `PATCH /api/settings`            | admin                 | Update any subset: `tmdbApiKey`, `openSubtitlesApiKey`, `openSubtitlesUsername`, `openSubtitlesPassword`. Null clears a value.                                                                                                                                                                                                                       |

PINs are 4 to 6 digits. Five wrong PINs in a row lock the profile for 15 minutes; during the lockout even the right PIN returns 423.

## Schemas defined for upcoming routes

Grouped by the sub-phase that will route them.

- **Items (1.17)** — `ProgressState` (always null on `ItemSummary.progress` until 1.17).
- **Playback (1.11 to 1.14)** — `DeviceProfile`, `PlaybackDecideRequest`, `PlaybackDecision`, `PlaybackMethod`, `ProgressUpdateRequest`.

Each of these appears twice in `components.schemas`, once as `Name` (output) and once as `NameInput` (input). That is how `fastify-type-provider-zod` emits schemas; clients should use the plain `Name` variant for responses and `NameInput` for request bodies.
